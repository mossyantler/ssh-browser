설치 순서 보기
  1. 독립형 SSH Browser Helper.app을 다운로드해 /Applications 또는 ~/Applications에 놓고, 일반 앱처럼 한 번 실행하세요. 첫 실행 시 Chrome Native Messaging에 자동 등록됩니다. Helper 창은 닫아도 돼요. 확장이 필요할 때 Chrome이 native host를 실행합니다.
  2. 별도로 받은 SSH-Browser-Extension.zip을 원하는 영구 보관 폴더에 압축 해제하세요. chrome://extensions에서 개발자 모드를 켜고, ‘압축해제된 확장 프로그램을 로드합니다’로 manifest.json이 들어 있는 extension 폴더를 선택해 주세요. Helper.app에는 확장이 포함되지 않으며, 확장 파일을 복사·삭제·이동하지 않습니다.
  3. 이 화면에서 ‘도우미 설치 확인’을 누르세요.

미리보기에서는 실제 설치 확인이나 SSH 연결을 실행하지 않습니다.
